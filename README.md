# 毎日の献立（プロトタイプ v1）

スマホのブラウザで使う、毎日の献立づくりアプリです。サーバー不要の静的サイトで、データは端末の localStorage に保存されます。

## 機能
- **今日の献立** … 主菜・副菜・汁物を表示。1品ずつ／まるごと入れ替え。料理をタップするとレシピ詳細。
- **1週間の献立** … 今日から7日分を自動作成。週内で同じ料理を使わず、主菜の主な食材（肉・魚・卵・豆腐）が偏らず前日と続かないように調整します。日ごとの「おまかせ」入れ替え、2日間の「入替」、料理をタップして好きなレシピを選ぶこともできます。
- **買い物リスト** … 1週間分の材料を売り場ごとにまとめて合算（例：玉ねぎ 1/2個＋1個 → 1と1/2個）。チェック状態は保存されます。調味料は折りたたみ。自由に項目を追加可能。
- **人数設定（1〜4人）** … 今日の画面の歯車、または買い物リストの「◯人分」から変更。レシピは2人分で保存し、レシピ詳細と買い物リストの分量を 人数/2 倍で換算します（「適量」「少々」はそのまま）。
- **レシピ一覧** … 家庭料理40品を収録（分量は2人分）。検索・絞り込み・お気に入り（お気に入りは献立に選ばれやすくなります）。自分のレシピを追加・編集・削除、組み込みレシピをコピーしてアレンジも可能。

## ローカルで動かす
```sh
cd kondate-app
python3 -m http.server 8000
# → http://localhost:8000/ を開く
```
ES Modules と Service Worker を使うため、`file://` で直接開くのではなく HTTP サーバー経由で開いてください。

## 公開（GitHub Pages など）
このフォルダの中身をそのままリポジトリに置き、GitHub Pages を有効にするだけで動きます（パスはすべて相対パスなので、`/リポジトリ名/` のようなサブパスでもOK）。
公開後、スマホのブラウザで開いて「ホーム画面に追加」するとアプリのように使えます。

ファイルを更新したときは `sw.js` の `CACHE_VERSION` を上げてください。

## ファイル構成
```
index.html              画面の骨組み（ヘッダー・タブバー）
manifest.json / sw.js   PWA（ホーム画面追加・オフライン対応）
css/style.css           スタイル（モバイルファースト）
icons/                  アプリアイコン
js/app.js               画面切り替え（#today / #week / #shopping / #recipes）
js/store.js             localStorage 保存とデータアクセス
js/planner.js           献立の自動生成ロジック（純粋関数）
js/actions.js           画面から呼ぶ操作（store と planner をつなぐ）
js/shopping.js          買い物リスト生成（分量の合算）
js/data/recipes.js      組み込みレシピ
js/data/ingredients.js  材料の売り場分けルール
js/lib/                 汎用ヘルパー・UI部品（ボトムシート、トースト、アイコン）
js/components/          レシピ詳細・編集フォーム・レシピ選択・設定（人数）シート
js/views/               4つの画面
screenshots/            動作確認時のスクリーンショット
```
