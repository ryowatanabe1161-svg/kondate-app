# デミさんクッキング

スマホのブラウザで使う、毎日の献立づくりアプリです（旧名「毎日の献立」。リポジトリ名・公開URLはそのまま）。サーバー不要の静的サイトで、データは端末の localStorage に保存されます。

## 機能
- **今日の献立** … 主菜・副菜・汁物を表示。1品ずつ／まるごと入れ替え。料理をタップするとレシピ詳細。朝・昼・お弁当をオンにすると、食事ごとの折りたたみセクション（今の時間の食事が開いた状態）と1日の合計カロリーを表示します。
- **朝ごはん・昼ごはん・お弁当** … 設定（今日の画面の歯車）の「献立を作る食事」でオン・オフ（既定は夕ごはんだけ。夕ごはんはいつも作ります）。
  - **朝ごはん**：主食＋おかず＋汁物・飲み物（和朝食・洋朝食。主食とおかずのジャンルをそろえやすくしています）。
  - **昼ごはん**：麺・丼・パスタ・チャーハン・サンドなどの一品＋小鉢・スープ（小鉢はオフにもできます）。
  - **お弁当**：主菜＋副菜2品（作り置きOK・冷めてもおいしいおかず）。作る曜日を選べます（既定は月〜金）。
  - 1週間の画面は食事のタブで切り替え。入れ替え・おまかせ・料理の選択・固定・条件（時短・節約・ヘルシー・カロリー目標）・星評価・冷蔵庫の提案・カロリー表示・買い物リスト（今週・来週とも全部の食事をまとめて合算）がすべての食事で使えます。カロリー目標は1食あたりで、朝ごはんはその8割を目安にします。
- **1週間の献立** … 今日から7日分を自動作成。週内で同じ料理を使わず、主菜の主な食材（肉・魚・卵・豆腐・麺・丼）が偏らず前日と続かないように調整します（麺・丼は週1回まで）。ジャンル（和・洋・中・その他）も偏らないようにし、洋・中・その他は2日続けません。副菜・汁物は主菜とジャンルが合うものを選びやすくしています。日ごとの「おまかせ」入れ替え、2日間の「入替」、料理をタップして好きなレシピを選ぶこともできます。
- **献立の条件** … 1週間の画面の「条件」または設定シートから設定（端末に保存）。
  - **平日は時短**：主菜だけ／3品合計の調理時間の上限（主菜15・20・30分、合計30・40・45・60分）。「休日はゆっくりOK」をオンにすると土日は制限なし（祝日は判定しません）。
  - **節約モード**：節約タグや安い食材（鶏むね・豆腐・もやし・卵など）の料理を選びやすくし、高めの食材（牛肉・えび・鮭など）を出にくくします。
  - **ヘルシーモード**：ヘルシーな料理を選びやすく、揚げ物を出にくくします。1食（1人分・夕ごはんとお弁当はご飯別）のカロリー目標（500〜800kcal）も設定可能（朝ごはんは主食込みで8割が目安）。
  - **ジャンルの好み**：和食・洋食・中華を多めに。
  - 条件は週の自動作成・「作り直す」・日ごとのおまかせ・今日の入れ替えに使われます。合うレシピが足りないときは条件をゆるめて選び、トーストでお知らせします。有効な条件は1週間の画面にチップで表示されます。
- **日・料理の固定** … 1週間の画面の「固定」で日ごと、料理をタップして「この◯◯を固定する」で1品ずつ固定できます。固定した日・料理は「作り直す」や条件を変えての作り直し、おまかせ入れ替えでも変わりません（固定した日は「入替」できません）。
- **来週の献立** … 1週間の画面の「今週／来週」で切り替え。来週（今週の最終日の翌日から7日分）は今週の料理となるべく重ならないように作られ、今週と同じように編集・固定できます。今週が終わると、来週の献立がそのまま今週の献立になります（作り直されません）。
- **買い物リスト** … 「今週の分／来週の分」を切り替え可能（チェック状態も週ごとに保存）。献立を作るすべての食事（朝・昼・お弁当・夕）の1週間分の材料を売り場ごとにまとめて合算（例：玉ねぎ 1/2個＋1個 → 1と1/2個）。チェック状態は保存されます。調味料は折りたたみ。自由に項目を追加可能。
- **人数設定（1〜4人）** … 今日の画面の歯車、または買い物リストの「◯人分」から変更。レシピは2人分で保存し、レシピ詳細と買い物リストの分量を 人数/2 倍で換算します（「適量」「少々」はそのまま）。
- **カロリー・栄養の目安** … 今日の献立と1週間の各日に、1人分の合計カロリー（ご飯別）とたんぱく質・脂質・炭水化物の目安を表示。1週間の画面には1日平均・7日合計も出ます。材料から「たんぱく質（たんぱく源の料理数）」「野菜（種類の数）」「炭水化物（麺・丼なら主食込み／それ以外はご飯を添えて）」を ◎○△ で表示します。値はレシピデータからの大まかな目安です。
- **星評価（1〜5）** … レシピ詳細で星を付けられます（今日の料理カードをタップしても評価可）。星はレシピ一覧・献立の料理選び・冷蔵庫の提案にも表示され、一覧では評価で絞り込み・評価順に並べ替えができます。おまかせ献立では ★5 がかなり出やすく、★4 は出やすく、★2 は出にくく、★1 はほぼ出なくなります。
- **冷蔵庫から提案** … あまっている食材をタップまたは入力すると、そろっている食材が多い順にレシピを提案（ある食材・足りない食材を表示）。レシピを開いたり、そのまま今日の献立にしたりできます。レシピデータとの照合だけで動くのでオフラインでも使えます（表記ゆれ例：タマネギ→玉ねぎ、豚肉→豚○○肉）。「冷蔵庫」タブと、今日の画面のボタンから開けます。
- **くわしい作り方** … 組み込みレシピはすべて4〜8手順で、切り方・大きさ、火加減（弱火・中火・強火）、時間、でき上がりの目安（竹串がすっと通るまで 等）、調味料を入れる順番まで記載。レシピ詳細に「コツ・ポイント」も表示します（自作レシピにも入力欄あり）。
- **レシピ一覧** … 和・洋・中・韓国/エスニックの家庭料理205品を収録（分量は2人分）。夕ごはん133品に加え、朝ごはん26品・昼ごはん23品・お弁当のおかず23品。既存の料理も合うものは複数の食事に使います（候補数：朝39・昼48・お弁当50・夕133）。食事（朝・昼・お弁当・夕）や主食・飲み物でも絞り込めます。各レシピにジャンル・タグ（時短・作り置き・節約・ヘルシー・子ども向けなど）・1人分のカロリー目安・絵文字付き。検索・絞り込み・お気に入り（お気に入りは献立に選ばれやすくなります）。自分のレシピを追加・編集・削除、組み込みレシピをコピーしてアレンジも可能。

- **見た目** … 料理ごとに、器（お皿・どんぶり・小鉢・汁椀・お茶碗・木のボード・グラス）の手描き風インラインSVGと大きな絵文字をやさしい色の背景で表示（外部画像なし・オフラインOK）。レシピ詳細の上部には大きなイラスト。今日の画面は大きなロゴ・暖かいグラデーション・フライパンのマスコット。カードの入場、入れ替え時のシャッフル＆スピン、星のぽんと弾むアニメーション、買い物リストのチェック、タブ切り替えのアニメーションつき（端末の「視差効果を減らす／アニメーションを減らす」設定ではすべて止まります）。

## ローカルで動かす
```sh
cd kondate-app
python3 -m http.server 8000
# → http://localhost:8000/ を開く
```
ES Modules と Service Worker を使うため、`file://` で直接開くのではなく HTTP サーバー経由で開いてください。

## 公開（GitHub Pages など）
このフォルダの中身をそのままリポジトリに置き、GitHub Pages を有効にするだけで動きます（パスはすべて相対パスなので、`/リポジトリ名/` のようなサブパスでもOK）。
公開後、スマホのブラウザで開いて「ホーム画面に追加」するとアプリのように使えます。

ファイルを更新したときは `sw.js` の `CACHE_VERSION` を上げてください。

## ファイル構成
```
index.html              画面の骨組み（ヘッダー・タブバー）
manifest.json / sw.js   PWA（ホーム画面追加・オフライン対応）
css/style.css           スタイル（モバイルファースト）
icons/                  アプリアイコン
js/app.js               画面切り替え（#today / #week / #shopping / #recipes）
js/store.js             localStorage 保存とデータアクセス（保存データの移行）
js/meals.js             食事（朝・昼・お弁当・夕）の定義と設定
js/planner.js           献立の自動生成ロジック（純粋関数）
js/actions.js           画面から呼ぶ操作（store と planner をつなぐ）
js/shopping.js          買い物リスト生成（分量の合算）
js/fridge.js            冷蔵庫の食材とレシピの照合・ランキング
js/nutrition.js         カロリー・栄養・バランスの目安の計算
js/data/nutrients.js    組み込みレシピの P/F/C の目安値
js/data/recipes.js      組み込みレシピ（夕ごはん＋食事のタグ）
js/data/recipes-meals.js 朝ごはん・昼ごはん・お弁当のレシピ
js/data/ingredients.js  材料の売り場分けルール
js/lib/                 汎用ヘルパー・UI部品（ボトムシート、トースト、アイコン、料理のイラスト art.js）
js/components/          レシピ詳細（星評価）・編集フォーム・レシピ選択・設定（人数・食事）シート・献立の条件シート・栄養の目安表示
js/views/               5つの画面（今日・1週間・買い物・レシピ・冷蔵庫）
screenshots/            動作確認時のスクリーンショット
```
